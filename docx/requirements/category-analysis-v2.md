# 分类系统需求分析 v2.0

> **编写原则**：本文档从纯需求出发，不参照现有代码。现有实现如有出入，以本文档为准。

---

## 一、分类树模型

阿斯塔洛斯 Wiki 的分类体系是一个**树形结构**：

```
物品              ← 一级
├── 武器          ← 二级
│   ├── 剑        ← 三级 ← 最大深度
│   ├── 枪
│   └── 戟
├── 药品          ← 二级
├── 防具          ← 二级
└── 杂物          ← 二级
```

**深度规则**：最深三级。不允许创建四级分类（如"短剑"挂在"剑"下）。

## 二、分类页面子级菜单

> 这是用户访问分类页面时看到的导航 UI。

### 核心概念

分类页面是一个**单页**。所有子级菜单在这个页面内**从上往下展开**，不跳转、不弹窗。

### 具体行为

#### 场景 A：一级分类页面（如"物品"）

```
┌─────────────────────────────────────────────┐
│ h1: 物品                                     │
│ ┌──────┬──────┬──────┬──────┐              │
│ │ 全部 │ 武器 │ 药品 │ 杂物 │  ← 等宽固定按钮  │
│ └──────┴──────┴──────┴──────┘              │
│ ───────────────────────────────────          │
│          (页面列表区域)                        │
└─────────────────────────────────────────────┘
```

**入口**：用户从侧边栏或首页点击"物品"进入。

**L1 栏**：显示该分类的**直接子分类** + 首位「全部」按钮。
- 每个按钮**等宽**（flex: 1），占满整行
- 按钮圆角矩形状，深色模式下可见边框
- 「全部」按钮选中时表示查看所有子分类的页面

**点击"武器"**：页面标题变为"武器"，L1 栏保持不变（仍是物品的子分类）。页面下方**出现 L2 栏**：

```
┌─────────────────────────────────────────────┐
│ h1: 武器                                     │
│ ┌──────┬──────┬──────┬──────┐              │
│ │ 全部 │ 武器 │ 药品 │ 杂物 │  ← L1（不变）    │
│ └──────┴──────┴──────┴──────┘              │
│ ┌──────┬──────┬──────┐                      │
│ │ 全部 │  剑  │  枪  │  ← L2（新出现，等宽）  │
│ └──────┴──────┴──────┘                      │
│ ───────────────────────────────────          │
│          (武器下的页面列表)                     │
└─────────────────────────────────────────────┘
```

**点击"剑"**：同理，L3 栏在 L2 下方出现：

```
┌─────────────────────────────────────────────┐
│ h1: 剑                                       │
│ ┌──────┬──────┬──────┬──────┐              │
│ │ 全部 │ 武器 │ 药品 │ 杂物 │  ← L1         │
│ └──────┴──────┴──────┴──────┘              │
│ ┌──────┬──────┬──────┐                      │
│ │  剑  │  枪  │  戟  │  ← L2                │
│ └──────┴──────┴──────┘                      │
│ ┌──────┐                                     │
│ │ 全部 │  ← L3（剑无子分类，仅"全部"按钮）     │
│ └──────┘                                     │
│ ───────────────────────────────────          │
│          (剑下的页面列表)                       │
└─────────────────────────────────────────────┘
```

#### 场景 B：叶子分类页面（如"药品"无子分类）

L1 栏仍然显示同级分类，但不出现 L2 栏：
```
┌─────────────────────────────────────────────┐
│ h1: 药品                                     │
│ ┌──────┬──────┬──────┬──────┐              │
│ │ 全部 │ 武器 │ 药品 │ 杂物 │              │
│ └──────┴──────┴──────┴──────┘              │
│ ───────────────────────────────────          │
│          (药品下的页面列表)                     │
└─────────────────────────────────────────────┘
```

### 关键约束

| 约束 | 说明 |
|------|------|
| **等宽** | 所有 Tab 按钮等宽（`flex: 1`），占满内容区宽度 |
| **同页** | L1/L2/L3 不跳转，在同一页面从上往下依次出现 |
| **无重复** | 每个分类在栏位中只出现一次，不重复显示 |
| **选中态** | light 模式：选中按钮背景稍暗；dark 模式：选中按钮背景稍亮 |
| **动效** | 子栏展开用 200ms ease-out 下滑动效 |
| **首项"全部"** | 每个栏位的第一项始终是"全部"，点击后回到当前分类页 |

## 三、管理员创建分类

### 创建约束

| 父分类深度 | 可创建深度 | 示例 |
|:--:|:--:|------|
| 无（一级） | 一级 → 二级 | 创建"武器"挂在"物品"下 |
| 二级 | 二级 → 三级 | 创建"剑"挂在"武器"下 |
| 三级 | **禁止** | 无法给"剑"添加子分类 |

### UI 约束

- 创建表单中，父级选择器仅显示深度 ≤ 2 的分类
- 三级分类的「添加子分类」按钮**置灰**并提示"已达最大深度"

## 四、删除分类与页面迁移

### 流程

```
管理员点击"删除"
    ↓
检查：是否有子分类？
    ├─ 是 → 阻断，提示"请先删除子分类"
    └─ 否 → 继续
         ↓
    检查：是否有页面使用该分类？
    ├─ 否 → 确认后直接删除
    └─ 是 → 弹出迁移对话框
              ├─ 显示：被删分类名 + 页面数量
              ├─ 下拉选择：目标分类（排除自身及子孙）
              └─ 点击"迁移并删除"
                   ↓
              DELETE /api/categories/{id}?migrateTo={targetId}
                   ↓
              后端：批量更新页面 categoryId → 删除分类
                   ↓
              刷新列表
```

## 五、管理员页面 UI 标准

所有管理员页面（8个）的 UI 必须：

| 元素 | 标准 |
|------|------|
| 表格 | `el-table` 全局暗色覆盖 + mono 字体表头 + uppercase + tracked |
| 按钮 | `btn btn-primary`（主操作）/ `btn btn-ghost`（次要） |
| 标题 | `eyebrow` + `section-title` 二级标题体系 |
| 分页 | `el-pagination` 无圆角 + 暗色适配 |
| 弹窗 | `el-dialog` 分割线 header/footer |
| 表单 | `el-input` 无圆角 + focus 边框高亮 |
| 删除按钮 | 红色文字 + 边框 |

## 六、与旧代码的差异

| 旧实现 | 新需求 | 改动 |
|--------|--------|------|
| L1/L2/L3 用 flex+margin | 等宽 `flex:1` | 改 CSS |
| Tab 点击跳转路由 | 同页展开，路由跳转到对应分类 | 改逻辑 |
| 子级从 API 单查 | 从 store 树查找 | 保持（已验证） |
| 三级约束有但提示不明确 | 置灰按钮 + 文字提示 | 增强 UI |
| 删除无迁移 | `?migrateTo=` 参数 | 已补全 |
