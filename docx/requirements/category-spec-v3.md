# 分类系统需求规格 v3.0

> 取代 v2.0。以本文档为准。

---

## §1 分类树模型

最深三级。不允许四级。

```
物品 (一级)
├── 武器 (二级)
│   ├── 剑 (三级) ← 最深
│   ├── 枪 (三级)
│   └── 戟 (三级)
├── 药品 (二级)
├── 防具 (二级)
└── 杂物 (二级)
```

## §2 分类页面 — 固定宽度 Tab + 换行布局

### 核心规则

| 规则 | 值 |
|------|----|
| 每个 Tab 按钮宽度 | **固定 160px** |
| Tab 按钮高度 | **固定 36px** |
| 溢出行为 | `flex-wrap: wrap` → 超出宽度换到下一行 |
| 栏间距 | L1 与 L2 之间 8px，L2 与 L3 之间 4px |
| 子栏弹出位置 | 在上级栏**正下方**，不是弹窗、不是侧滑 |

### 场景示例

#### 物品页面

```
┌──────────────────────────────────────┐
│ h1: 物品                              │
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │
│ │ 全部 │ │ 武器 │ │ 药品 │ │ 杂物 │ │  ← L1, 160px 固定宽
│ └──────┘ └──────┘ └──────┘ └──────┘ │
│                                       │
│       (页面列表)                       │
└──────────────────────────────────────┘
```

#### 点击"武器"后 — L2 在 L1 下方弹出

```
┌──────────────────────────────────────┐
│ h1: 武器                              │
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │
│ │ 全部 │ │ 武器 │ │ 药品 │ │ 杂物 │ │  ← L1
│ └──────┘ └──────┘ └──────┘ └──────┘ │
│ ┌──────┐ ┌──────┐ ┌──────┐           │
│ │ 全部 │ │  剑  │ │  枪  │           │  ← L2, 在 L1 正下方
│ └──────┘ └──────┘ └──────┘           │
│                                       │
│       (武器下的页面列表)                │
└──────────────────────────────────────┘
```

#### 点击"剑"后 — L3 在 L2 下方弹出

```
┌──────────────────────────────────────┐
│ h1: 武器 (不变，仍在武器页)             │
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │
│ │ 全部 │ │ 武器 │ │ 药品 │ │ 杂物 │ │  ← L1
│ └──────┘ └──────┘ └──────┘ └──────┘ │
│ ┌──────┐ ┌──────┐ ┌──────┐           │
│ │ 全部 │ │  剑  │ │  枪  │           │  ← L2
│ └──────┘ └──────┘ └──────┘           │
│ ┌──────┐ ┌──────┐ ┌──────┐           │
│ │ 全部 │ │ 短剑 │ │ 长剑 │           │  ← L3, 剑的子分类
│ └──────┘ └──────┘ └──────┘           │
│                                       │
│       (武器下的页面列表，不变)           │
└──────────────────────────────────────┘
```

### 关键：L3 为终点

- L3 的 Tab **不可点击导航**。L3 只展示，表示"这是最底层分类"。
- 没有任何操作会从 L3 产生 L4。**三级封顶，硬编码保证**。
- 如果要查看 L3 某个分类的页面，点击该 L3 Tab → 跳转到该分类页面 → 该页面的 L1/L2 显示其同级/子级，但不会出现 L4。

### 换行行为

当 Tab 总宽度超过内容区宽度时：

```
┌──────────────────────────────────────┐
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │
│ │ 全部 │ │ 武器 │ │ 药品 │ │ 杂物 │ │
│ └──────┘ └──────┘ └──────┘ └──────┘ │
│ ┌──────┐ ┌──────┐                     │  ← 溢出换行
│ │ 防具 │ │ 饰品 │                     │
│ └──────┘ └──────┘                     │
└──────────────────────────────────────┘
```

## §3 管理员 — 三级创建约束

| 创建场景 | 允许? | 父级选择器 |
|---------|:--:|------|
| 创建一级分类（无父级） | ✅ | 不选父级 |
| 在一级下创建二级 | ✅ | 可选所有一级分类 |
| 在二级下创建三级 | ✅ | 可选所有二级分类 |
| **在三级下创建四级** | ❌ | 三级分类不显示在选择器中 |

- 树形视图中的**三级分类节点**的「添加子分类」按钮置灰，hover 时提示"已达最大深度（3级）"

## §4 管理员 — 删除分类与页面迁移

### 删除流程

```
点击删除按钮
    ↓
弹窗确认 (ElMessageBox.confirm)
    ↓ 确认
检查是否有子分类？
    ├─ 有 → ElMessage.warning("请先删除子分类") → 中断
    └─ 无 → 检查是否有页面？
              ├─ 无 → 调用 DELETE /api/categories/{id} → 成功
              └─ 有 → 弹出迁移对话框
                        ├─ el-select 选择目标分类
                        └─ 点"迁移并删除"
                              → DELETE /api/categories/{id}?migrateTo={targetId}
```

### 迁移对话框 UI

```
┌──────────────────────────────────┐
│ 删除分类 — 页面迁移               │
├──────────────────────────────────┤
│                                  │
│ 分类「武器」下有 5 个页面，        │
│ 请选择迁移目标：                  │
│                                  │
│ ┌──────────────────────────────┐ │
│ │ 选择目标分类          ▼      │ │  ← el-select
│ └──────────────────────────────┘ │
│                                  │
│       [取消]  [迁移并删除]        │
└──────────────────────────────────┘
```
