# 符文锻造术

符文锻造术是[[阿斯塔洛斯]]在永夜纪元后发展出的核心技术，由[[虚空法师团]]于纪元 15 年首次系统化。该技术通过雕刻特定图案激活符文矿脉中封存的太阳残余能量，实现照明、供暖、锻造和防御等功能。

## 原理

符文矿脉本质是裂变战争中碎裂的太阳碎片。这些碎片蕴含巨大的残余热能和光能，但在自然状态下处于休眠。符文锻造术通过在矿脉表面雕刻特定的能量导引图案（即"符文"），唤醒并引导这些能量。

基本锻造流程：

```
1. 勘探矿脉 → 确定品质和深度
2. 表面处理 → 清除冰层和杂质
3. 符文雕刻 → 按用途选择图案
4. 能量激活 → 注入初始魔力触发
5. 稳定化   → 调整符文密度防止过载
```

## 应用

- **城邦能源**：冰辉城的全城照明和供暖依赖符文矿脉阵列
- **武器锻造**：符文武器能产生光热效果，是对抗暗影生物的利器
- **结界维持**：城邦外围的防护结界由大型符文阵列驱动

## 限制与风险

符文锻造术需要在矿脉 proximity 范围内使用，远离矿脉则效果急剧衰减。此外，过度开采可能导致裂隙共振——矿脉能量波动引发虚空裂隙扩张，后果不堪设想。
