# 分类系统需求规范 v3.0

> **编写原则**：本文档从零编写，不参照现有代码。
> **核心纠正**：分类页面内的所有 Tab 点击均在**同一页面**内完成，不跳转路由、不刷新页面。

---

## §1 分类树模型

```
物品               ← 一级
├── 武器           ← 二级
│   ├── 剑         ← 三级（最深）
│   ├── 枪         ← 三级
│   ├── 戟         ← 三级
│   └── 刀         ← 三级
├── 药品           ← 二级
├── 防具           ← 二级
└── 杂物           ← 二级
```

**规则**：最深 3 级。4 级不允许。

## §2 分类页面的 Tab 导航

### §2.1 核心原则

> **整个页面不跳转。** 用户进入分类页面后，所有 L1/L2/L3 Tab 的点击都是页面内的状态切换。URL 不变，浏览器不导航，页面不刷新。

### §2.2 Tab 层级定义

| 层级 | 数据来源 | 展示位置 | 示例 |
|:--:|------|------|------|
| L1 | 当前分类的**同级兄弟分类** | 标题下方第一行 | `[全部] [武器] [药品] [防具] [杂物]` |
| L2 | 当前**选中 L1 Tab** 的子分类 | L1 下方弹出 | `[全部] [剑] [枪] [戟] [刀]` |
| L3 | 当前**选中 L2 Tab** 的子分类 | L2 下方弹出 | `[全部] [短剑] [长剑]` |

- 每个层级的第一项永远是「全部」按钮
- 「全部」表示回到上一级的视图（显示该级父分类的所有页面）

### §2.4 按钮规范

| 属性 | 值 |
|------|----|
| 宽度 | **等宽**（`flex: 1`），占满整行 |
| 最小高度 | 44px（可点击区域） |
| 字体 | `var(--mono)`，uppercase，小号 |
| 选中态 light | 背景稍暗（`rgba(0,0,0,0.05)`） |
| 选中态 dark | 背景稍亮（`rgba(255,255,255,0.10)`） |
| 动效 | 点击时 scale(0.97) 微回弹，200ms |
| 换行 | 按钮数量超过屏幕宽度时自动换行 |

### §2.5 Tab 列表操作逻辑

```
用户点击某个 Tab：
  1. 如果该 Tab 就是当前已选中的 → 取消选中（收起该层及以下）
  2. 如果该 Tab 是「全部」→ 收起该层及以下，回到上一级
  3. 如果该 Tab 是新的 → 选中该 Tab，展开下一层（若存在子分类）
```

## §3 管理员创建分类

### §3.1 层级约束

| 创建时父级深度 | 允许 | 创建结果深度 |
|:--:|:--:|:--:|
| 无父级 | ✅ | 一级 |
| 一级 | ✅ | 二级 |
| 二级 | ✅ | 三级 |
| 三级 | ❌禁止 | — |

### §3.2 UI 表现

- 父级选择器：仅列出深度 ≤ 2 的分类
- 添加子分类按钮：对三级分类置灰 + tooltip「已达最大深度」
- 弹窗表单内实时显示当前将创建的分类深度

## §4 删除分类与页面迁移

```
管理员点击「删除」
  ↓
是否有子分类？
  ├── 是 → 阻断 + 提示「请先删除子分类」
  └── 否 ↓
该分类是否有页面引用？
  ├── 否 → 二次确认 → 直接删除
  └── 是 → 弹出迁移弹窗
            ├── 显示：分类名 + 引用页面数
            ├── 下拉框：可选目标分类（排除自身及子孙）
            └── 按钮：「迁移并删除」
                 ↓
            DELETE /api/categories/{id}?migrateTo={targetId}
```

## §5 管理员页面 UI 一致

所有管理员页面共享同一个视觉标准：

| 元素 | 规范 |
|------|------|
| 表格表头 | `font-family: var(--mono)`, `font-size: 11px`, `uppercase`, `letter-spacing: .08em` |
| 主操作按钮 | `btn btn-primary` |
| 次要操作 | `btn btn-ghost` |
| 删除操作 | 红色边框 + 红色文字 |
| 页面标题 | `eyebrow` + `section-title` |
| 搜索/筛选 | `el-input` 全局暗色覆盖 |
| 分页 | `el-pagination` 无圆角 |
| 弹窗 | `el-dialog` 分割线 header/footer |

## §6 需求总结（供 AI 记忆）

```
1. 分类页面 = 单页。L1/L2/L3 全部在页内切换。不跳路由。
2. Tab 等宽 flex:1，44px 起，自动换行，暗色/亮色选中态。
3. 点击 Tab 展开下一层，「全部」收起该层。
4. 管理员创建最长 3 级，4 级置灰。
5. 删除分类 = 检查子分类 → 检查页面引用 → 迁移弹窗 → DELETE ?migrateTo=。
6. 管理员所有页面 UI 统一。
```
