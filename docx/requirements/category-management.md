## FR1 — 分类页面子级菜单展示

### 场景
用户在「分类页面」浏览某一分类（如"物品"）。

### 要求

1. 页面顶部显示当前分类标题（h1），其下为**等宽横向标签栏**：
   - **L1 栏**：父级分类下的所有同级分类 + 首位「全部」按钮
   - 示例：`[全部] [武器] [药品] [防具] [杂物]`（等宽排列，占满内容区宽度）

2. 点击 L1 某个标签（如「武器」）→ 跳转到该分类页面 → 在其标题下**等宽弹出 L2 栏**：
   - **L2 栏**：该分类的子分类 + 首位「全部」按钮
   - 示例：`[全部] [剑] [枪] [戟] [刀]`

3. 点击 L2 某个标签（如「剑」）→ 跳转 → 在其下**等宽弹出 L3 栏**：
   - **L3 栏**：该子分类的子分类（若有）+ 首位「全部」
   - 示例：`[全部] [短剑] [长剑] [双剑]`

4. **所有栏位等宽** — L1/L2/L3 栏宽度与内容区一致，不缩进。
5. **不出现重复标签** — L1 栏不包含已在其他层级显示的项。
6. **选中态** — light 模式下背景稍暗，dark 模式下背景稍亮。
7. **弹出动效** — 200ms ease-out 展开，120ms ease-in 收起。

### 数据来源

`getCategoryById(id)` 返回**扁平对象（无 children）**，因此子分类数据需从 `categoryStore.categories` 树中通过 `findInTree()` 递归查找。

## FR2 — 管理员创建分类的层级约束

### 场景
管理员在后台「分类管理」页面创建新分类。

### 规则

| 条件 | 约束 |
|------|------|
| 无父分类 | 可创建（一级分类） |
| 父分类为一级 | 可创建子分类（二级） |
| 父分类为二级 | 可创建子分类（三级） |
| 父分类为三级 | **禁止**创建子分类（已到最大深度） |

### 后端约束

- `POST /api/admin/categories` 接收 `{ name, description, parentId }`
- 若 `parentId` 对应的分类已是三级（深度=3），后端应返回 400 错误
- 若 `parentId` 对应的分类深度 ≥ 4，后端应阻止创建

### 前端表现

- 创建表单中，父级选择器仅显示深度 ≤ 2 的分类
- 若分类已达三级，该选项置灰并提示"已达最大深度"

## FR3 — 删除分类与页面迁移

### 场景
管理员删除一个分类。如果该分类下有页面（`wiki_pages.category_id = 被删分类ID`），则必须将这些页面迁移到另一个分类，不可直接删除。

### 流程

```
管理员点击"删除分类"
  │
  ├─ 后端查询：该分类是否被页面引用？
  │   ├─ 是 → 弹出「迁移页面」对话框
  │   │       │
  │   │       ├─ 显示：被删分类名 + 受影响的页面数量
  │   │       ├─ 下拉选择：目标分类（可选所有分类，排除自身及子孙）
  │   │       └─ 确认删除 + 迁移
  │   │
  │   └─ 否 → 直接删除
  │
  └─ 完成后刷新分类列表
```

### 错误处理

| 错误场景 | 处理 |
|---------|------|
| 迁移目标为空 | 提示"请选择目标分类" |
| 被删分类有子分类 | 提示"请先删除子分类" |
| 后端返回错误 | 显示错误消息 |
| 网络超时 | 提示重试 |

### 后端接口（需新增）

```
DELETE /api/admin/categories/{id}?migrateTo={targetCategoryId}
  - 若 migrateTo 为空且该分类无页面：直接删除
  - 若 migrateTo 非空：迁移所有页面 → 删除分类
  - 若 migrateTo 为空且有页面：返回 400 "该分类下有 N 个页面，请指定迁移目标"
```

## FR4 — 管理员页面 UI 一致性

### 要求

所有管理员页面的 UI 必须遵循设计系统：

| 元素 | 类名 | 说明 |
|------|------|------|
| 表格 | `el-table`（全局覆盖） | dark 主题自动适配 |
| 按钮 | `btn btn-primary` / `btn btn-ghost` | 统一按钮风格 |
| 标题 | `section-title` / `eyebrow` | 统一排版层级 |
| 分页 | `el-pagination`（全局覆盖） | 暗色适配 |
| 表单 | `el-form` + `el-input`（全局覆盖） | 统一输入框 |
| 弹窗 | `el-dialog`（全局覆盖） | 统一弹窗 |
| 卡片容器 | `card` | 内容分组 |
| 搜索/筛选 | `el-input` + `search-box` | 搜索栏样式 |

无例外。旧 `classic-*` / `hermes-*` 类名在管理页面中已废弃。
