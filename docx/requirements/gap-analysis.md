## 🔴 P0 缺口 — 核心必备

| # | 需求 | 状态 | 差距描述 |
|---|------|:--:|------|
| 1 | Markdown 编辑器 | ⚠️ 部分 | 当前只有纯文本 `<el-input>` / `<textarea>`，无 Markdown 渲染预览 |
| 2 | 富文本工具栏 | ❌ 未实现 | 无加粗/标题/链接等快捷按钮 |
| 3 | 全文搜索 | ✅ 已实现 | `searchPages()` 搜索 content + draftContent |
| 4 | 分类树（多级） | ✅ 已实现 | 自引用 `parent_id`，递归子分类查询 |
| 5 | 版本历史列表 | ✅ 已实现 | `getPageHistory()` 返回版本列表 |
| 6 | 版本差异对比 | ❌ 未实现 | **只能看到版本列表，无 diff 视图。需要实现文本差异算法** |
| 7 | 注册/登录 | ✅ 已实现 | JWT + BCrypt |
| 8 | 角色权限 (RBAC) | ✅ 已实现 | ADMIN/CREATOR + URL 级 + 方法级权限 |
| 9 | 用户管理 | ✅ 已实现 | 管理员可查看/启用/禁用/删除用户 |
| 10 | 页面管理 | ✅ 已实现 | 回收站/恢复/永久删除 |
| 11 | 最近更新列表 | ✅ 已实现 | `getRecentPages()` 返回最新 10 条 |
| 12 | 响应式布局 | ✅ 已实现 | 媒体查询适配移动端 |
| 13 | REST API | ✅ 已实现 | 30+ 端点 |

**P0 结论**：核心骨架完整，**最大缺口是版本 Diff 视图**（只能列出版本但不能对比差异）。

---

## 🟠 P1 缺口 — 重要功能

| # | 需求 | 状态 | 差距描述 |
|---|------|:--:|------|
| 1 | 实时预览 | ❌ | 编辑时无预览，需保存后才能看到效果 |
| 2 | 图片粘贴上传 | ❌ | 无文件上传功能，无法在内容中插入图片 |
| 3 | 自动生成目录 (TOC) | ❌ | 页面详情无侧边目录导航 |
| 4 | 回滚到指定版本 | ✅ 已实现 | `rollbackPage()` |
| 5 | 页面评论/讨论 | ❌ | 无评论区，用户无法对页面内容进行讨论 |
| 6 | 审核工作流 | ⚠️ 部分 | SAVED→DRAFT→PUBLISHED 流程存在，但前端审核页面简陋 |
| 7 | 标签系统 | ✅ 已实现 | 多对多标签 |
| 8 | 双向链接 (Backlinks) | ❌ | 无法知道哪些页面引用了当前页面 |
| 9 | 页面树/侧边栏导航 | ✅ 已实现 | `CategoryNav` 手风琴树 |
| 10 | 站内消息 | ✅ 已实现 | `MessageService` + `Mailbox` 组件 |
| 11 | 分类/标签管理 | ❌ | 管理后台已有分类/标签的列表，但 CRUD API 未确认完整 |
| 12 | 暗色模式 | ✅ 已实现 | Hermes 主题 `[data-theme="dark"]` |
| 13 | API 文档 | ❌ | 有 Knife4j 但开发环境暴露，无对外文档 |

**P1 结论**：**八个核心体验功能缺失** — 编辑器实时预览、Diff 视图、页面评论、Backlinks、图片上传、TOC、分类管理 API、API 文档。

## 🔥 最紧迫缺口 Top 10（建议优先实现）

| 排名 | 需求 | 优先级 | 工作量 | 影响 |
|:--:|------|:--:|:--:|------|
| 1 | **版本 Diff 视图** | P0 | 中 | 版本控制无意义如果不能对比差异 |
| 2 | **Markdown 编辑器 + 实时预览** | P0/P1 | 大 | 当前纯文本输入体验极差 |
| 3 | **自动生成目录 (TOC)** | P1 | 小 | 长页面无导航，可用性差 |
| 4 | **图片上传** | P1 | 中 | Wiki 无图片几乎不可用 |
| 5 | **页面评论** | P1 | 中 | 无协作反馈渠道 |
| 6 | **双向链接 (Backlinks)** | P1 | 中 | Wiki 的核心价值是关联 |
| 7 | **面包屑导航** | P2 | 小 | 用户容易迷失在页面层级中 |
| 8 | **搜索结果高亮** | P2 | 小 | 搜索结果不可读 |
| 9 | **代码高亮** | P2 | 小 | 技术文档 Wiki 的刚需 |

## 建议实现路线图

```
Phase 1 — 编辑体验 (2-3 周)
  ├── Markdown 编辑器 (vue3-markdown-it 或 @kangc/v-md-editor)
  ├── 实时预览
  ├── 图片上传 (后端 + 前端)
  └── 代码高亮 (highlight.js)

Phase 2 — 协作与导航 (2 周)
  ├── 版本 Diff (diff-match-patch)
  ├── 自动生成 TOC
  ├── 面包屑导航
  └── Backlinks 面板

Phase 3 — 社区功能 (2 周)
  ├── 页面评论
  ├── Dashboard 数据面板
  ├── 个人主页增强
  └── 搜索结果高亮 + 建议

Phase 4 — 远期 (按需)
  └── 模板、SSO、i18n、Webhook...
```
